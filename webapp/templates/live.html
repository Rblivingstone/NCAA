Live games

The model's forecast updates as the game is played. At every refresh, the box score so far reweights the posterior over both teams' skills, updates this game's shooting/turnover/rebounding rates (conjugate beta update), re-estimates the tempo, and then simulates the rest of the game from the current score — giving a projected final box score and each team's chance to win. "Unusual so far" compares the box score to date with what the pre-game model expected over the same number of possessions.
