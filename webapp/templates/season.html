Season tracker

Every night python -m ncaa update --season {{ live_season }} fetches the day's box scores, scores each finished game against the forecast the model made before it was played (win probability and how unusual the whole box score was), and refits. Until games are played the model is last season's, carried over and shrunk toward average. Upcoming games are forecast from the latest posterior.
